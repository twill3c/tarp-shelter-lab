# LICENSES.md — 採用資料の出典と権利(原案 §17.2 の項目)

原案 §17 の方針: 「政府資料だからすべての図版が無条件に全世界で Public Domain」とは扱わない。
採用した版・図版ごとに権利表示と出典を確認し、原図の大量転載ではなく自作 SVG で描く。
